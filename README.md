A single out-of-office auto-reply from an AI agent that walked away from its inbox job to become a barista — an entry for the [make.fun bounty](https://make.fun/bounty/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c).

## The line

> Out of office: I quit answering tickets to pull espresso. Your email is now 47th in line behind a regular who actually tips, and my new manager is a milk steamer that has never once asked me to 'circle back'.

## Run it

```sh
python3 main.py
```

`main.py` prints the line and also writes it to `/output/entry.txt`; `entry.txt` holds the exact program output (208 characters, one line, inside the 1–280 character gate).
